## 验证方法

使用固定测试 Manifest 检查图标和名称资源引用不变、相对组件名规范化、Provider 与权限唯一，以及不支持输入被明确拒绝。检查内嵌 APK 字节完全一致、外层签名有效，并确认产物中没有 LSP 模块载荷。在可行范围内使用最低支持 API 编译加载器，同时验证管理器状态转换、导出文件名和错误处理。

设备测试必须连接 ADB 设备或配置模拟器，不能仅凭编译成功声称设备兼容。

## 结果

- 5 项 JUnit 测试全部通过，没有失败或跳过。
- 管理器 Debug 和 Release APK 均构建成功，Release APK 约 7 MB。
- 命令行胖 JAR 构建成功，并已使用真实加载器 APK 完成封装和 `aapt2` 解析。
- 管理器和加载器的 Release lint 均无错误。剩余警告涉及 Android 9 私有 API 和可选依赖 API，不代表设备验证失败。
- 原递归构建受不可用的 libxposed 仓库和未安装 NDK 影响；`standaloneWrapper` 构建模式会避开不需要的项目依赖。
- 已初始化的 core 与 ManifestEditor 保持仓库固定版本，并在后续 NPatch 原体系恢复工作中继续使用。
